# Quoridor

コリドール（Quoridor）のデジタル実装です。Android 向けのローカル対戦ボードゲームです。

## 概要

9×9 のボード上で、プレイヤーは自分のコマをゴール（対面の端）まで移動させることを目指します。
ただし各プレイヤーは壁を置いて相手の進路を妨害することができます。
全員が必ずゴールへの経路を持ち続けるというルールのもと、移動と壁配置を交互に行う戦略性の高いボードゲームです。

## ルール

- プレイヤーは毎ターン、**コマを1マス移動する**か**壁を1枚置く**かを選びます。
- 壁は2マス分の長さがあり、縦または横に配置できます。
- **いずれかのプレイヤーの経路を完全に塞ぐ壁の配置は禁止**されています。
- 相手のコマに隣接している場合、コマを飛び越えて移動できます（飛び越えルール）。
- 自分のコマがゴールライン（対面の端）に到達したプレイヤーの勝利です。

## 機能

- **2・3・4人対戦**（ローカルマルチプレイ）
- 壁の枚数: 2人プレイ時は10枚・3人は6枚・4人は5枚
- 壁配置バリデーション（全プレイヤーの経路を保証）
- 飛び越えルール対応
- 縦・横の壁方向切り替え
- ポーズメニュー（再開 / リセット / タイトルへ戻る）
- 遊び方パネル
- 勝利画面

## 動作環境

- Android 5.1 以上（API Level 22）

## インストール

1. [Releases](../../releases) から最新の APK をダウンロードします。
2. Android 端末に APK をインストールします。
   - 初回インストール時は「提供元不明のアプリ」を許可する設定が必要な場合があります。

## ビルド方法

1. [Unity 6000.3.8f1](https://unity.com/releases/editor/archive) をインストールします。
2. Unity Hub でこのリポジトリのフォルダを開きます。
3. `File > Build Settings` から **Android** プラットフォームを選択し、ビルドします。
